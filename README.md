# Prompt Wizard Duels

A two-player game that teaches prompt engineering.

- `backend/` — Cloudflare Workers + Durable Objects API. Start with [backend/CONTRACT.md](backend/CONTRACT.md) and [backend/README.md](backend/README.md).
- `app/` — frontend (React Native / Expo), coming later.
- `challenges/` — challenge set library (see [backend/CHALLENGES.md](backend/CHALLENGES.md)).
